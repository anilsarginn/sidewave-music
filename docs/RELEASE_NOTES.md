# Sidewave 0.1.0

Initial public-source release by Sargın Labs.

- Self-hosted web app and API with per-account libraries, playlists and playback history.
- Native Android client with phone downloads, widgets and Android Auto media browsing.
- Separate Sidewave branding, application ID and user-configurable server origin.
- Docker Compose setup with an internal resolver and optional Navidrome library.
- Own-certificate Android update publishing, reproducible build instructions and automated checks.
- MIT license for original code, third-party attribution, synthetic-data screenshots and a silent UI demo.

No private installation database, music files, account credentials, signing keys or previous deployment history are included. The Android APK built during preparation is a development build, not a production-signed release. Provider availability and physical-device/car behavior require separate validation.
